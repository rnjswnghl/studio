# 컷앤노트 — 짤·카드 스튜디오

인생네컷과 오래된 디지털카메라의 뒷면에서 착안한 로컬 전용 이미지 편집기입니다. PNG/JPEG 사진을 최대 4장까지 불러오고, 한글 문구·글자색·위치·비율·프레임·원본 이미지 스티커를 바꾼 뒤 PNG로 저장할 수 있습니다.

## 실행

```bash
node scripts/serve.mjs
```

브라우저에서 `http://localhost:3000`을 엽니다. Node.js만 있으면 별도 패키지 설치 없이 실행됩니다. 로그인이나 사진 서버 업로드는 없습니다. Express 서버를 사용하려면 `npm install` 후 `npm run serve`로 실행합니다.

## 구현 범위

- PNG/JPEG 파일 로드와 지원하지 않는 형식·손상 파일 오류 처리
- 1:1(1080×1080), 4:5(1080×1350), 9:16(1080×1920) 미리보기 및 동일 크기 PNG 저장
- 첨부 원본 기반 디카, 세로 필름, 가로 필름, 폴라로이드, REC, 뷰파인더 6종 프레임
- 여러 텍스트의 개별 글꼴·색상·크기·회전·자유 위치 조정과 원본 이미지 스티커
- 사용자 템플릿 생성·재호출·수정·삭제 및 새로고침 유지
- 사진 칸 더블클릭 교체와 드래그 위치 조정
- 사진 원본·칸·위치를 포함한 JSON 완전 백업·복원, 손상/필수 누락 시 기존 작업 보호
- 새 작업은 텍스트 없이 시작하며 ‘텍스트 추가’를 누르면 편집창이 펼쳐짐

## 레퍼런스 에셋

`assets/references`에 제공받은 원본 16장을 보관합니다. `assets.js`는 원본 좌표로 스티커를 자르고 외곽에 연결된 단색 배경을 투명하게 처리합니다. 내부의 흰 반사광과 눈동자는 보존합니다. 사진 프레임은 원본 비율을 유지하고 사진 창에 업로드 이미지를 합성합니다. 크기와 가로·세로 위치를 조절할 수 있으며 PNG에도 동일하게 반영됩니다. 유리 하트·반짝·달과 버블 시트도 선택 목록에 포함합니다. 체크무늬가 포함되었던 4종은 ImageGen으로 배경을 제거한 RGBA PNG를 `assets/stickers`에서 사용합니다. 원본은 `assets/references`에 보관하며 생성형 편집으로 반사광의 세부 표현은 달라질 수 있습니다. 메탈·유리 하트 15종과 추가 표정 30종도 제공합니다.

## 자유 편집

소재를 클릭할 때마다 독립된 스티커가 추가됩니다. 캔버스에서 드래그하거나 편집 대상 목록에서 선택하여 위치·크기·회전·불투명도·좌우 반전을 조절하고 복제·삭제·앞뒤 순서를 변경할 수 있습니다. 방향키(Shift로 크게 이동)와 Delete도 지원합니다. 문구는 드래그 이동과 크기·회전, 사진 프레임은 위치·크기 조절이 가능합니다. 실행 취소/다시 실행과 JSON 백업·사용자 템플릿은 여러 스티커의 배치 상태를 보존합니다.

사진별 확대·회전·칸 교환·삭제 및 PNG/JPEG 사용자 이미지 스티커를 지원합니다. 프레임도 회전할 수 있습니다. 사진까지 자동 저장하며 브라우저 저장 용량을 초과하면 JSON 백업 안내를 표시합니다.

실행 취소/다시 실행은 사진 업로드·교체·삭제, 비율·문구·프레임 변경, 스티커 변형 및 사용자 템플릿 생성·수정·삭제에 적용됩니다. 회전한 문구의 실제 범위를 클릭해 이동할 수 있으며, 프레임은 자체 중심을 기준으로 회전합니다. 사용자 템플릿은 꾸미기 설정을 저장하고, 사진 원본까지 보관하려면 작업 백업을 사용합니다.

브라우저 기능 검증: Playwright와 Edge가 설치된 환경에서 로컬 서버 실행 후 `node scripts/qa-browser.cjs`. 별도 위치의 Playwright는 `PLAYWRIGHT_MODULE`, 확인할 배포 주소는 `QA_URL` 환경 변수로 지정합니다. 결과·검증용 PNG는 Git에서 제외한 `qa/`에 생성합니다. 이 검증은 새 브라우저 세션과 생성한 시험 이미지만 사용합니다.

공개 주소: https://cutandnote.rnjswnghl.chatgpt.site

배포 빌드: `npm run build` → `dist`. 기존 Sites 프로젝트 설정은 `.openai/hosting.json`에 보관합니다.

사진 칸은 프레임의 실제 창 수(1/3/4개)와 일치합니다. 빈 칸에 첫 사진을 자동 반복하지 않으며, 이전/다음 칸 교환은 보이는 칸 사이에만 적용됩니다. 프레임 변경으로 보이지 않는 사진은 보관 상태로 표시하고 유지합니다. READY-MADE CUTS 미리보기 섹션은 제거했습니다.

## 다중 텍스트 편집 (2026-09-28)

‘텍스트 추가’를 누를 때마다 독립 텍스트가 생성되고 편집창이 펼쳐집니다. 목록 또는 캔버스에서 기존 텍스트를 선택하여 수정하고, 편집창을 접어도 내용은 유지됩니다. 텍스트는 최대 100개, 각각 최대 120자·3줄을 표시합니다. 복제·삭제·실행 취소·다시 실행을 지원합니다.

캔버스 드래그, 방향키(Shift로 크게 이동), 가로·세로 위치 슬라이더로 원하는 위치에 놓습니다. 글꼴은 기본 고딕(Noto Sans KR), 명조(Noto Serif KR), 고운 돋움, 개구쟁이 손글씨(Gaegu), 나눔 펜, 나눔 붓 6종입니다. 웹폰트 로딩을 기다려 미리보기와 PNG에 같은 글꼴을 적용하며 연결 실패 시 기본 글씨체 표시 안내가 나옵니다.

텍스트 배열은 자동 저장, 사용자 템플릿, JSON 백업에 포함됩니다. 기존 단일 문구 작업은 글꼴·색·크기·위치·회전·외곽선을 보존해 자동 변환합니다. 추가 검증: `node scripts/qa-text.cjs` (Playwright 설정은 위와 동일).


## 직접 만들기와 저장 형식 (2026-10-04)

기존 흑백·그레이 UI를 유지하며 빈 캔버스, 모노 듀오(2컷), 컨택트 시트(4컷), 에디토리얼(3컷)을 추가했습니다. 직접 만들기에서는 사진칸을 최대 4개 추가·삭제하고 각각의 가로/세로 위치와 너비/높이를 조절합니다. ‘캔버스에서 사진칸 이동’을 켜면 칸을 드래그하고, 끄면 사진 크롭 위치를 조절합니다. 빈 캔버스에 사진을 업로드하면 사진 수에 맞춰 칸을 생성합니다. 프레임 전환 시 사진은 보관되며 실행 취소로 이전 구성을 되돌릴 수 있습니다.

저장 형식에서 PNG, JPEG, PDF를 선택합니다. PDF는 캔버스 비율을 유지한 한 페이지 이미지 문서입니다. 편집 가능한 원본은 ‘JSON 저장’을 사용합니다. JSON에는 사진 원본, 사용자 스티커, 모든 텍스트와 사진칸 좌표·크기·레이어 변형이 포함되어 다시 열었을 때 그대로 복원됩니다. 내 템플릿에는 사진 원본을 제외한 구성과 꾸미기 설정이 저장됩니다.

추가 검증: `node scripts/qa-layout.cjs`. 직접 만들기, 사진칸 드래그, 실행 취소, JSON 왕복 및 손상 배치 거부, 세 비율 PDF, PNG/JPEG, 반응형 화면을 확인하며 `qa/`에 화면 캡처와 출력 파일을 생성합니다.


## Dark chrome studio (2026-10-04)

검정·차콜 패널과 실버 버튼으로 편집 UI를 개편했습니다. 데스크톱은 한 화면의 3열 작업 공간이며 패널 내부에서만 스크롤합니다. 모바일은 캔버스와 사진/텍스트/캔버스/소재 전환 탭을 사용합니다. 사진·텍스트·캔버스 도구는 아코디언, 소재는 템플릿/스티커/레이어/저장 탭, 템플릿은 6개씩 페이지 전환, 스티커는 가로 카테고리 필터로 탐색합니다.

긴 화면 설명을 제거하고 ! 도움말 버튼의 말풍선으로 이동했습니다. 마우스 hover, 키보드 focus, 터치 클릭으로 열 수 있으며 Escape로 닫습니다. 모든 select와 버튼·슬라이더·입력창에 동일한 다크 스타일을 적용했습니다. 기존 편집·원본 JSON·출력 기능은 유지합니다.

UI 검증: `node scripts/qa-ui.cjs`. 기존 브라우저 검증도 `scripts/ui-qa.cjs`를 통해 실제 탭·접기·템플릿 페이지를 전환한 뒤 기능을 확인합니다.
