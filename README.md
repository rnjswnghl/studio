# 컷앤노트 — 짤·카드 스튜디오

인생네컷과 오래된 디지털카메라의 뒷면에서 착안한 로컬 전용 이미지 편집기입니다. PNG/JPEG 사진을 최대 4장까지 불러오고, 한글 문구·글자색·위치·비율·프레임·연필선 스티커를 바꾼 뒤 PNG로 저장할 수 있습니다.

## 실행

```bash
npm run serve
```

브라우저에서 `http://localhost:4173`을 엽니다. 별도 설치, 로그인, 서버 업로드가 없습니다.

## 구현 범위

- PNG/JPEG 파일 로드와 지원하지 않는 형식·손상 파일 오류 처리
- 1:1(1080×1080), 4:5(1080×1350), 9:16(1080×1920) 미리보기 및 동일 크기 PNG 저장
- 은빛 디카, 크림 네컷, 35mm 필름, 피크닉 체크 기본 템플릿
- 문구, 색상, 크기, 위/가운데/아래 위치와 연필선 스티커
- 사용자 템플릿 생성·재호출·수정·삭제 및 새로고침 유지
- 사진 칸 더블클릭 교체와 드래그 위치 조정
- 사진 원본·칸·위치를 포함한 JSON 완전 백업·복원, 손상/필수 누락 시 기존 작업 보호
- 서로 다른 문구·비율을 가진 완성본 3종 미리보기

## 검증

```bash
npm test
npm run samples
```

개인정보 보호 근거: 앱 소스에는 `fetch`, `XMLHttpRequest`, `sendBeacon`, `WebSocket` 호출이 없고 이미지 처리는 브라우저 Canvas에서만 일어납니다.
