# 고정 검사 v1 · 정확히 10개

구현 시작 전에 고정한다. A/B는 동일한 검사 ID·입력·기대값을 사용한다. 실패를 해결하기 위해 삭제·완화·기대값 변경을 하지 않는다. 기존 14개 Node 검사는 별도 회귀 검사이며 이 10개에 더하지 않는다.

실행: `node scripts/qa-t05.cjs`. 브라우저: Edge / Playwright. 각 검사는 빈 브라우저 저장소에서 시작한다. 이름·이미지는 공개 합성 시험값이다.

| ID | 입력 및 행동 | 관찰 가능한 기대값 |
|---|---|---|
| T05-01 | ‘하트 여행’, ‘Chrome Note’, ‘여행 기록’ 저장 후 ` 여행 `, `CHROME`, Unicode 분해된 ‘하트’ 검색; 결과 선택 | 이름 부분 검색·공백·대소문자·Unicode 정규화가 적용되고, 선택한 템플릿 ID가 작업 상태에 반영된다. |
| T05-02 | 빈 저장소 → 템플릿 3개 저장 → `없는 이름` 검색 → 초기화 → ‘하트 여행’ 검색 후 이름 변경·삭제 → 새로고침 | 저장 없음/검색 없음 안내가 구분된다. 초기화 시 3개 복구. 수정·삭제 즉시 결과 갱신. 저장 데이터는 유지되고 검색어는 초기화된다. |
| T05-03 | 하트 스티커 선택·잠금 후 드래그, 방향키, 수치 입력, 크기/회전 퀵 도구, 반전·삭제·복제·앞뒤 변경 시도 | 레이어 ID·개수·순서·위치·크기·회전·불투명도·반전 값이 전부 유지된다. 아래 요소도 움직이지 않는다. |
| T05-04 | 잠금 → 실행 취소 → 다시 실행 → 잠금 해제 → 방향키 이동 | 잠금 false → true가 복원되고 해제 후 다시 이동할 수 있다. |
| T05-05 | 잠금·번호가 있는 작업 JSON 저장/복원; 기존 필드 없는 JSON 복원; `locked:"yes"`인 JSON 복원 | 정상 왕복은 잠금·번호 유지. 기존 작업은 읽을 수 있다. 잘못된 잠금 타입은 오류와 함께 기존 작업을 보존한다. |
| T05-06 | 같은 하트 3개 추가 → 첫 번째를 앞으로 → 두 번째 삭제 → 같은 하트 추가·복제 | 서로 다른 번호 1/2/3 부여. 순서 변경에도 ID별 번호 유지. 삭제 후 기존 번호 유지. 신규·복제 번호는 현재 최대보다 큼. |
| T05-07 | 같은 파일명 `heart.png`의 사용자 스티커 2개 업로드; 같은 텍스트 `안녕` 2개 추가·복제 | 사용자 스티커 이름 1/2, 텍스트 이름 1/2/3으로 구분되고 ID도 모두 다르다. |
| T05-08 | 격자 기본 상태 확인 → 켜기 → 세 비율 변경 → 스티커 드래그 → 끄기 | 처음 꺼짐. 켜짐 상태가 표시되고 비율마다 격자 픽셀이 달라진다. 드래그 가능. 끄면 가이드가 사라진다. |
| T05-09 | 동일한 빈 흰 캔버스를 격자 꺼짐/켜짐으로 각각 PNG·JPEG·PDF 저장, JSON 저장 | PNG/JPEG/PDF 바이트가 각각 같으며 JSON 작업과 템플릿에 격자 상태가 없다. 미리보기 픽셀은 가이드 켜짐에 따라 달라진다. |
| T05-10 | 390×844 화면에서 검색·잠금·번호·격자 조작 → 내 템플릿 저장·재호출 → 새로고침 | 모바일에서 도구 조작 가능. 템플릿 재호출·새로고침 후 잠금과 ID별 번호 유지. 격자는 새로고침 후 꺼짐. 런타임 예외 없음. |

실행 결과 JSON은 `qa/t05-<단계>-<시각>.json`에 생성된다. 공개 증거는 검토한 집계 결과만 `docs/evidence/`에 보관한다.
